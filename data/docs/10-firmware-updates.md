# Firmware Updates and Release Notes

## How updates work
Firmware updates are delivered over Wi-Fi through the Corvane Home app. With Auto Update enabled, updates install at 03:00 local time. An update takes about 6 minutes; do not switch the fan off at the wall during this time. If an update is interrupted, the fan shows E7 and rolls back to the previous version.

## Version 3.2.1 (August 2025)
Current version. Adds WPA3-Personal Wi-Fi support. Makes speed 1 quieter on DC models. Fixes false E6 errors when the remote was idle for a long time.

## Version 3.1.0 (February 2025)
Adds Breeze mode on DC models. Adds the 8-hour option to the sleep timer.

## Version 3.0.0 (September 2024)
Adds Bluetooth-only local control. Adds energy reporting on DC models.
